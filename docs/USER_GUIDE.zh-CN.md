# 千里眼 · FileSight 2.1

原生 macOS App 与文件名搜索工具；当前构建适用于 macOS 13 及以上的 Apple Silicon Mac。发布包为 `dist/FileSight.zip`，解压得到「千里眼.app」。

## 使用

将解压后的「千里眼.app」放入「应用程序」，打开后可按默认快捷键 `⌘↑` 呼出搜索框。系统访问权限应授予安装位置的 App。

- 文件搜索默认为「下载」。也可从范围菜单选择一个或多个本地目录。每个目录首次只读授权后会在后续启动自动恢复；可在设置中取消。App 搜索独立读取 macOS 标准本地应用位置，无需文件目录授权。千里眼不要求全盘访问，不递归跨越挂载点。
- 支持中文、英文、扩展名，忽略英文大小写；空格分隔的多个关键词同时匹配文件名。同名文件分别展示路径。
- 本机 App 会先于文件结果显示，不等待文件查询；支持系统语言名称、原始英文名、完整拼音和首字母，回车启动。
- 支持类型与日期组合筛选，例如 `最近1个月 发票 pdf`。类型或日期被识别后会显示为可移除标签。
- 搜索包含隐藏文件、子目录及 package 内文件；每批显示 100 项，可以继续加载全部匹配项。空输入不列出全部索引。
- 默认「名称优先」：完整文件名或去扩展名名称优先，然后开头匹配、包含匹配；同级最近修改优先。
- 可切换修改时间、创建时间、文件类型、文件名及方向。时间默认最新优先；类型按扩展名分组，同组始终最近修改优先；文件名按自然数字顺序排列。
- 文件结果双击后在 Finder 中定位，App 结果双击后启动；两者都可复制完整路径。不直接打开文档，没有删除、编辑、移动或重命名功能。
- 运行期间自动更新新增、改名、移动、删除和修改的文件。通常只重读发生变化的目录；文件事件丢失时重新核对授权范围。可按 `⌘R` 手动刷新。
- 菜单栏眼睛图标：左击呼出／收起，右击显示快捷菜单。`⌘↑` 默认全局呼出／收起，`esc` 收起；`↑↓` 选择，`↩` 定位 Finder，`⌘⇧C` 复制路径，`⌘Q` 退出。
- 在顶部菜单栏右键点击千里眼图标，打开「设置…」更改呼出快捷键。点击当前快捷键，出现“按下快捷键”后直接按下新组合，即时保存；Esc 或点击其他位置取消。注册失败会保留原设置。无需辅助功能或输入监控权限。
- `⌘↑` 也用于 Finder 返回上一级；千里眼运行且成功注册时会优先响应，可在快捷键设置中更换组合。
- 「设置…」还提供外观、登录时启动、搜索诊断和 GitHub 项目入口。登录启动默认关闭，开启后由 macOS 管理；登录时只显示菜单栏图标，不弹搜索框或自动授权目录。
- App 常驻菜单栏，不显示 Dock 图标；收起后索引保留，再次呼出不会重新扫描。面板高度随结果数变化。

快捷键会先显示并聚焦面板，再异步更新索引状态。大范围查询会渐进显示当前最佳结果；超过时间上限后提示继续输入，不会无限停在「搜索中」。系统拒绝读取、磁盘断开或云端目录尚未落盘时，菜单栏「设置…」里的「搜索诊断…」会说明原因。千里眼不主动下载云端内容，不扫描网络卷，也不跟随符号链接。外接本地磁盘需单独选择。

文件列表、搜索词和索引仅在内存中使用，不上传，不读取正文，不保存搜索历史。本机 App 沙盒内仅保存目录只读凭证、呼出快捷键和外观设置。主程序和 helper 均启用系统沙盒，无网络授权，外部文档只读。详见 [隐私与安全说明](../PRIVACY.md)。大范围扫描耗时和内存随文件数量增加。

## 构建与验证

需要 Apple Command Line Tools 和 Swift 5.10 或更新版本，无第三方依赖。

```sh
zsh scripts/build-app.sh
zsh scripts/verify.sh
```

构建产物为 `dist/千里眼.app` 和 `dist/FileSight.zip`。预览构建使用 ad-hoc 签名，未进行 Apple 公证；从网上下载后可能被 macOS 拦截。面向其他用户的正式安装包需要 Developer ID 签名与 Apple 公证。

自动验证创建临时文件树，检查超过 1000 条结果无截断、同名文件、隐藏文件、package 内部、Unicode 匹配、所有排序方向、重新扫描、范围切换取消及错误上报。测试结束会清理自己的临时文件。

另以四个同时阻塞的辅助进程注入故障，验证超时后能重启 worker，继续扫描队列里未受影响的目录。

索引按目录分块保存在内存中；搜索会预筛文件名，并只排序当前需要展示的结果。自动验证包含目录替换绕界、改名、移动、修改和删除测试。

安装更新时先退出千里眼，再运行 `zsh scripts/install-app.sh`。安装脚本会刷新 App 目录时间及系统注册，避免旧开发版记录和保留的旧目录时间使启动器继续显示默认图标；不会重置启动器布局。
