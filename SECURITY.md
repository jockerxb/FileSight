# Security Policy / 安全政策

## 报告安全问题

请使用 GitHub 的 [Private Vulnerability Reporting](https://github.com/jockerxb/FileSight/security/advisories/new) 私下报告漏洞，不要创建公开 Issue。

报告时请说明受影响的 FileSight 版本、macOS 版本、复现条件和可观察结果。请使用示例文件名与路径，不要提交个人文档、真实路径、搜索词、账号或其他隐私信息。

当问题影响本地索引保密性、只读文件边界、App Sandbox、符号链接路径边界或无网络权限承诺时，请优先按安全问题报告。

## Reporting a vulnerability

Use GitHub [Private Vulnerability Reporting](https://github.com/jockerxb/FileSight/security/advisories/new). Do not open a public issue.

Include the affected FileSight version, macOS version, reproduction conditions, and observed result. Replace real filenames and paths with examples, and do not submit personal documents, queries, account details, or other private information.

Treat issues affecting local-index confidentiality, read-only file boundaries, App Sandbox, symlink/path containment, or the no-network-entitlement guarantee as security reports.

## Supported versions / 支持版本

当前仅支持 GitHub Releases 中最新的预览版。Only the newest preview release on GitHub Releases is supported.
